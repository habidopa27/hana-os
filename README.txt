HANA OS V1

This is a static Progressive Web App.

Current features:
- Persistent daily entries using browser localStorage
- Mood, stress, inner peace, overall day
- What I did + activity tags
- Multiple structured learning entries
- Optional journal
- Edit/delete history
- 7-day structured weekly review
- JSON backup export/import
- PWA manifest + offline cache + Home Screen icons

IMPORTANT: Data is local to the browser/device. Export backups regularly. Cloud sync and AI weekly synthesis are not included yet.

To publish and get a URL, upload the CONTENTS of this folder to a static host such as GitHub Pages, Netlify, or Vercel. Once opened in Safari on iPhone, use Share > Add to Home Screen.
